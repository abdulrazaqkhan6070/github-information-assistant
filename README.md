# GitHub Information Assistant

An AI-powered GitHub assistant built with n8n and a GitHub-connected AI Agent.

## What It Does

This AI Agent can retrieve publicly available GitHub information using connected GitHub tools.

It can:

- Fetch GitHub profile details for a specified username
- Retrieve available profile information such as name, company, blog, location, followers, and following
- Explore repositories of a specified GitHub user or organization
- Retrieve available repository information
- Answer GitHub-related questions using connected tools
- Clearly explain when a requested GitHub operation is not supported

## Example

User:

> Fetch the GitHub profile details for Octokit.

The agent retrieves the available public profile information through the connected GitHub tool.

## Technologies

- n8n
- AI Agent
- GitHub API / GitHub Tools
- LLM
- Tool Calling
